Staging Area ( Git Add & Git Status ) 
bu video güzel anlatıyor :
https://www.youtube.com/watch?v=KnJdYBxAsNM&list=PLHN6JcK509bOrevTCFrSMeAfBtuib4Gpg&index=7

Biz git ile bir dosya oluşturmak istediğimizde önce local repository'ye ulaştırmamz gerek
Local repositorye bir dosya oluşturmadan önce dosyalarımızı  staging areaya taşıyoruz

stagng bir indexleme alanıdır local repository bu alandan gelen dosyaları kabul eder.

**git status

Bu komt bizim local repositorye taşıdığımız dosyalarla çalışma alanımız arasındaki farklılıkları gösterir
hangi dosya değişmiş
hangisi eklenmemiş
hangisi commit’e hazır sana bunu söyler

Eğer .git dosyası oluşturmadıysan(git init komutu ile) git status komutunu çalıştırmazsın

şimdi 2 tane terminal açtım ve birinden masaüstümdeki ege adlı klasördeyken birinden ise workarea diye yeni bir klasör oluşturttum
ege klasöründe daha önceden git init komutu çalıştırığım için halihazırda var zaten. ama workareada yok. 

* Eğer workareada **git status çalıştırırsam:

fatal: not a git repository (or any of the parent directories): .git 

Fatal error verir ve local repository yok bu yüzden karşılaştıramıyorum der.
bundan sonra burda da git init çalıştır ve depo kur.
--------------------

* Eğer ege dizininde **git status çalıştırırsam:
 On branch master
